# Verification reports

`reports/public-control-verify.latest.json` is runtime evidence generated by the external verifier and is intentionally not committed as source truth.

Historical committed reports are retained under `reports/history/` for audit provenance. A historical `GREEN` report means only that the declared external replay contract passed at its generation time; it is not permanent state and it never constitutes `VERIFRAX_SYSTEM_COMPLETE` authority.
